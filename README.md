# Desafio das Previsões

## Sobre o projeto

Este projeto foi desenvolvido para uma atividade escolar
sobre modelagem e previsão de fenômenos.

O objetivo é identificar situações mais fáceis e mais
difíceis de prever, considerando a estabilidade,
a volatilidade e os dados necessários.

## Tecnologias utilizadas

- HTML5: estrutura da página.
- CSS3: aparência e estilização.
- JavaScript: interação com o usuário.

## Situações analisadas

### Mais fáceis
1. Prever a altura média dos estudantes daqui a um ano.
2. Prever o tempo médio de deslocamento até a escola.

### Mais difíceis
1. Prever qual vídeo será o mais assistido da internet.
2. Prever o preço de uma moeda estrangeira amanhã.

## Como executar

1. Crie uma pasta chamada atividade-previsoes.
2. Salve os arquivos index.html, style.css e script.js
   dentro dessa pasta.
3. Abra o arquivo index.html no navegador.
4. Interaja com o teste de conhecimentos no final da página.

## Objetivo educacional

Compreender que fenômenos estáveis são geralmente mais
fáceis de prever, enquanto fenômenos voláteis apresentam
maior dificuldade de previsão.
